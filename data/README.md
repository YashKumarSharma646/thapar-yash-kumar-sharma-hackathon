# Data

Only public or synthetic data is used. No real client data.

| Folder | Contents | In git? |
|---|---|---|
| `sample/` | Small subsets used by replay mode, so the app runs without any downloads | Yes |
| `raw/` | Full public datasets, fetched by `python scripts/download_data.py` | No |
| `processed/` | Generated files (signals JSONL, synthetic portfolio, calibration tables) | No |

## Sources

| Dataset | Use | Source / License |
|---|---|---|
| Sentiment Analysis for Financial News (Financial PhraseBank) | Sentiment evaluation / fine-tuning | Kaggle `ankurzing/sentiment-analysis-for-financial-news`; Malo et al. (2014) |
| Tweet Sentiment's Impact on Stock Returns | Social source (replay), impact calibration | Kaggle `thedevastator/tweet-sentiment-s-impact-on-stock-returns` |
| Massive Stock News Analysis DB | News source (replay), impact calibration | Kaggle `miguelaenlle/massive-stock-news-analysis-db-for-nlpbacktests` |
| GDELT Project | Optional live global news feed | https://www.gdeltproject.org (open) |
| Yahoo Finance via `yfinance` | Market prices for calibration and stress shocks | https://github.com/ranaroussi/yfinance |
| Synthetic wholesale banking portfolio | Module B stress testing | Generated by this project (seeded) |

_Licenses to be verified per dataset before samples are committed._
